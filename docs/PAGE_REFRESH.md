# 0.2.8 页面统一、统计布局与圈注修正

## 已批准范围

保持云白青岚首页、液态底栏和训练操作位置。训练、统计、我的及动作库、模板/编辑器、周安排、历史/详情、身体、外观、备份页面采用统一内容区样式。三品牌六外观共用布局，不覆盖已有偏好，不加入演示记录。

`AppTheme.editorial`仅作用于PageBody内容：轻量描边面板、统一表单/列表、主页面大标题、分区短线；二级页面保留紧凑返回标题。训练页面和历史详情用preserveLayout保留原内边距和控件次序。训练首页突出继续/开始，工具归为一组；我的按偏好、身体与数据、关于分组。

## 统计交互与只读数据

- 保留7种TimeFilter，默认最近30天，通过单一周期按钮打开选择面板。
- 概览与动作趋势分开；动作选择只作用于趋势，不传入概览的Statistics.calculate。
- 六指标按两列/三列等高行排列，大字体或极窄内容区单列；图表明细默认折叠。
- 概览继续使用领域统计结果。展示层按日、最近90天按周一分桶、本年及全部按月聚合dailyVolume，不写库，总量保持。肌群按主要肌群完成组数显示横条和数值。
- 趋势从实际会话快照提取；每个完成组一个节点，按完成时间排序，相同时间保留源顺序。横轴为完成先后序列，日期仅作标记，并非等比例时间轴。点按显示日期/时间/重量，密集记录横向滚动。
- 动作ID与LoadKind共同确定曲线；外部总重量与哑铃单只重量分开展示。草稿、删除、未来和范围外组不进入曲线；辅助/有氧/未明确口径保留动作选项并明确无负重曲线。已删除的动作库条目仍可从保留历史快照查看记录。
- 只读整理位于statistics_presentation，数据库schema1、模型、领域统计、控制器、仓储和备份格式均未改变。界面筛选由原有独立导航分支保留，不写入业务设置。
