# 多语言

0.2.11起支持简体中文、繁體中文、English和跟随系统。入口：我的→语言；立即生效，通过原仓储事务保存。老数据没有language字段时保持简体中文。跟随系统识别英语及中文脚本/地区（Hant、TW/HK/MO），其他未支持语言回退简体。

## 实现

AppStrings作为Flutter LocalizationsDelegate加入MaterialApp，两个UTF-8词典位于assets/translations，简体中文使用源码消息。启动先加载离线资源，切换时同步读取缓存，避免首屏闪回其他语言。扩展语言需同时更新支持列表、语言选择项、备份字段验证、词典及测试。参数使用{0}等占位符，单次替换，插入的用户文本不再解释为参数。

只在明确的界面文案和固定分类处调用tr；不包裹通用Text、不按文本猜测用户名字，不改写已有动作/模板/训练名称、昵称、备注或历史快照。初始内置动作和示例模板也是已有库内容，沿用其原名。分类显示可翻译，筛选和保存值保持原来的稳定值。输入标签的展示翻译与字段key分开，切语言不会重建为另一组数据。

休息通知沿用ID71和rest_alerts_v2，更新语言时替换文案并沿用未来截止时间，不重启计时，不重置权限。应用进程运行时，跟随系统响应语言变化。取消后的提醒不会因后续语言刷新重新安排。系统对通知通道名称的显示与原生投递仍需分别验收，平台mock不能替代原生投递。

## 数据和兼容

language为可选设置字段，允许system/zh_Hans/zh_Hant/en，完整JSON包含它；schema和完整备份格式版本保持。新版本可读没有该字段的旧备份。带新设置的备份应在支持该设置的新版本恢复，旧版可能拒绝未知字段。

同时补全既有restPresetSeconds偏好的白名单与1–86400秒校验；该字段原先已经由休息页面写入，本轮仅使读取/备份验证与既有保存流程一致。数据库结构、计算、稳定ID/时间/删除标记不变。

导出文件名继续为Android真实应用名称＋本地日期，不随界面语言改名；JSON字段/CSV列和用户内容保持兼容。WebDAV凭据和系统权限仍不迁移，恢复时自动备份仍关闭。
