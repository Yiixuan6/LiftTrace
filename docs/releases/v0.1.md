# LiftTrace v0.1 · 首次公开发布

LiftTrace（练迹）是一款 Android 离线训练日志，帮助你记录每一组训练、安排计划和查看进步，无需注册账号。

## 主要功能

- 逐组记录重量、次数、完成状态、感受及备注，支持自由训练、暂停与继续。
- 动作库、自定义动作、训练模板和每周安排。
- 外部负重、哑铃单双侧、辅助器械及有氧记录。
- 休息倒计时、暂停、延长、跳过及系统提醒。
- 训练历史、训练量、肌群分布、逐组动作趋势和身体数据记录。
- 完整 JSON 备份恢复、CSV 导出及 WebDAV 备份。
- 三套品牌配色、浅色与深色模式，以及跟随系统外观。

## 下载安装

下载附件 **LiftTrace-v0.1.apk**，适用于 Android 8.0 及以上，包含 arm64-v8a、armeabi-v7a 和 x86_64 架构。源码可通过本页的 Source code 下载。

这是首次对外发布，GitHub 版本标签使用 **v0.1**。Android 应用内部仍显示 **0.2.10**，versionCode 为 **12**，包名为 `app.lianji.training`。

已有“练迹”安装时，先导出完整 JSON，再使用同签名安装包覆盖更新；不要通过卸载来更新。休息提醒需允许通知和相关提醒权限，部分手机还需允许后台运行。

## 当前边界

- 当前仅提供 Android 中文界面；iOS 和多设备双向同步尚未提供。
- WebDAV 为备份与恢复，实际服务兼容性及不同手机的后台策略需分别验证。
- 已有 Android API 36 设备验证记录；Android 8/9/13 等版本尚未完成实机覆盖，锁屏和长期省电场景也未全面验证。

本次公开发布复核了现有正式 APK 的身份、签名、通知资源、SHA-256，以及发布源码中的应用文件与既有构建源码快照的一致性；没有重新运行全部业务或设备测试。
