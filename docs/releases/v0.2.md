# LiftTrace v0.2 · 三语言支持与备份读取修复

## 新增

- 支持 **简体中文、繁體中文、English**，也可选择跟随系统。
- 在“我的 → 语言”切换后立即生效，并保存语言偏好。
- 界面、固定分类和休息提醒文案随语言变化；原有训练、动作、模板名称及备注保留原文。
- 英文长文案与大字号布局适配。

## 修复与兼容

- 修复已有休息时长偏好可能导致旧版拒绝读取本地数据或完整备份的问题。
- 完整备份支持保存语言设置，仍可读取没有语言字段的旧版备份；数据库结构与备份格式版本保持不变。
- 切换提醒语言时保留原休息截止时间，不重新开始计时。

## 下载安装

附件 **LiftTrace-v0.2.apk** 适用于 Android 8.0 及以上，包含 arm64-v8a、armeabi-v7a 和 x86_64。

GitHub 公开版本为 **v0.2**，Android 内部版本为 **0.2.11（13）**，包名仍为 `app.lianji.training`，沿用原正式签名，可覆盖更新 v0.1。

更新前尽量导出完整 JSON，安装时直接覆盖，避免卸载造成数据丢失。如果旧版已因休息偏好校验问题无法打开数据或导出，可先保留当前应用与数据，使用本版同签名 APK 覆盖更新，再立即导出并检查记录。不要清除应用数据或用旧备份覆盖当前数据。

带新语言设置的备份请使用本版或后续兼容版本恢复；旧版可能因不认识新字段而拒绝读取。切换界面语言不会翻译已保存的个人记录，导出文件名仍使用应用名称与本地日期。
