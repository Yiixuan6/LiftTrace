# 使用、安装、更新与恢复

当前版本0.2.9；最新组间休息修复见本文末节。手机正常QA包已保留更新，以下0.2.8说明为页面设计基线。

## 0.2.8 页面与统计

训练、我的及各二级页沿用首页的视觉风格；首页与液态底栏保持，正在训练页计时/休息/新增入口及动作和组倒序保持。

统计顶部通过时间范围按钮选择最近7/30/90天、本周/本月/本年/全部。“概览”始终包含全部动作，显示六项指标、训练量和肌群分布；“动作趋势”中再选择动作，选择不会影响概览。趋势每组一个点，同日多组不合并，点按查看完成时间和重量，记录多时可左右滑动。外部总重量和哑铃单只重量分别展示，辅助重量不进入负重曲线。详细数值默认折叠，右上角可查看统计口径。

当前手机已同签名保留更新至0.2.8；已有记录与其他业务数据逐字段保留，安装前新增记录也保留，完整备份仅在私有目录。输入标签统一在框外，备份页同组按钮大小统一，禁用状态也不改变尺寸。其他Android版本及旧格式/WebDAV外部待验项目仍按验收矩阵标注。

## 日常记录

首页开始自由训练或今日模板，有活动会话时继续。训练内可搜索动作、肌群/器械/收藏/最近筛选、自定义，管理模板和周一起始的安排。

直接在组卡输入重量/次数，完成后点击组内或底部主按钮。复制组默认为未完成，只有确认完成才计入实际量。哑铃填单只 kg 与实际左右次数；辅助 kg 单列，有氧填秒及适用距离/速度/阻力。无效字段就近提示并阻止误用旧值完成。

动作列表和各动作内的训练组均倒序显示：新动作在最上方，组例如第3组、第2组、第1组。新增或复制的组放在该动作组列表最上方；组号依原记录顺序，底部“完成下一组”仍完成原顺序最早未完成的组。历史详情共享倒序展示，存储数组不自动倒排；“上移动作”按屏幕方向移动。

训练页计时与实际完成组数合并为一张双列卡。“新增一组”和“添加动作”位于组间休息下方，普通字体并排，大字体自动换行。只有一个未跳过动作时直接新增组；有多个时先选择动作，可取消而不新增；没有可选动作时先添加动作。历史详情仍保留各动作下方的添组入口。

暂停扣训练时长，正常休息计入。离开页面/关闭应用后可从首页继续；“结束训练”才归入历史。未完成组不计实际量，历史可逐组编辑、删除、复制为模板。

身体数据按日期记录，围度可空。外观先预览再应用。无账号、登录或 AI 处方。

## 安装与更新

仅安装 release 目录中已验证签名 APK；未签名包只作构建验证，不能正常安装。安装时按系统提示允许所用文件管理器安装来源。

覆盖更新必须沿用 app.lianji.training、同一私钥，并递增 versionCode。先导出完整 JSON，再覆盖安装；不要先卸载，卸载会删除私有训练数据和凭据。签名私钥独立保管，不能从 APK 恢复。当前真实安装/覆盖/升级验收以矩阵状态为准。

## 本地备份

我的 → 备份与恢复 → 导出完整 JSON，包含训练/身体数据和可迁移设置，是明文文件，交给自己控制的位置保存。CSV 为训练分析，不能完整恢复。

选择练迹完整 JSON，查看数量并确认后替换本机业务数据。恢复前备份在私有 before-restore 目录，“导出最近恢复前备份”可取出。损坏/未知版本/无效内容会拒绝。私有安全备份也会随卸载删除，重要文件需显式外部导出。

旧网站样例尚未取得，不能直接导入；界面明确说明。

## WebDAV

填写已存在的 HTTPS 目录、用户名和密码/专用密码，保存后测试。连接验证读取；立即备份验证写入和回读。服务需允许 PROPFIND/PUT/GET/MOVE。每次独立快照，不覆盖历史。

自动备份默认关闭；主动启用后联网合并变化和后台重试，可能受省电影响延迟。列表先验证文件再恢复；恢复仍是替换本机、先本地安全备份。

凭据不进 JSON，换机重配。恢复关闭自动备份，不迁移权限或设备休息提醒。不会自动删除远端历史。

## 休息提醒

完成一组后自动开始该动作的休息，未设置时90秒；也可选60/90/120秒或自定义，暂停/继续/+30秒/取消。切到视频等其他应用后，到时使用系统横幅通知与振动，点通知返回训练。

在训练页“后台提醒设置”允许通知、精确提醒，并开启应用通知的横幅和振动。OPPO须同时开启应用通知总“振动”；若切到其他应用后不提醒，点“后台运行设置”，在本应用耗电管理允许后台行为（可能增加该应用耗电）。正式包与验证包需分别授权。页面会说明拒权或非精确调度限制，应用内计时仍可用；不绕过勿扰。完整步骤与实际验证边界见REST_REMINDERS.md。

## 0.2.9 组间休息

修复发布包通知组件无法启动的问题，初始化错误与未允许权限分别提示。点击时长立即开始，并在后续完成组时沿用；自定义支持1–86400整秒。暂停中+30仍保持暂停。底部倒计时旁可暂停/继续或跳过，无需滚回上方；跳过只结束休息，不改训练组。

手机已保留更新至0.2.9，完整备份前后业务数据一致。提醒按本应用系统通知/振动及后台设置执行；真实Release已验证其他App前台与熄屏投递/系统振动，安全锁屏和实际手感仍有单独验证边界。

## 0.2.10 导出名称与正式版迁移

完整JSON、分析CSV及恢复前备份导出，默认文件名统一为Android当前应用名称＋本地日期，例如 `练迹-2026-10-21.json`、`练迹-2026-10-21.csv`；验证包使用自己的真实名称。文件内容和完整备份格式不变。同一天导出同类型文件同名，由系统保存界面处理重名，请保留需要的历史副本。恢复前备份默认日期为本次导出日期，内容仍为被恢复前的原状态。

正式版包名 `app.lianji.training`，与验证版数据独立；先从验证版导出完整JSON并校验，再安装正式版，在“我的→备份与恢复→从JSON完整恢复”选择备份并确认，恢复后核对。系统权限和WebDAV凭据不迁移，自动备份会关闭，其他业务数据及外观偏好按完整恢复流程保留。不要为迁移卸载验证版。

## 0.2.11 语言

打开“我的→语言”，选择简体中文、繁體中文、English或跟随系统，立即生效并保存。系统为英文或繁体中文地区时按相应语言显示，未支持的系统语言使用简体中文；旧数据默认保持简体中文。语言偏好随完整备份保留，旧备份仍可恢复。自己填写的昵称、动作/训练/模板名称和备注保持原文，原有内置动作/模板名字也是库内容，不自动改写。通知文案使用所选语言；系统权限与后台限制不因换语言重置。

导出名称仍按Android应用名称＋日期；JSON字段与CSV列不随界面语言改名，保证已有分析/恢复流程。
